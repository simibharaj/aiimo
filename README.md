# ai, in my opinion · interactive editions

the interactive editions of [ai, in my opinion](https://aiimo.substack.com) by simi bharaj. a new one every tuesday.

each edition is six bites: what happened in ai this week, what i think about it, and one prompting skill you practice in a live terminal.

live at **https://simibharaj.github.io/aiimo/**

built with plain html, css and javascript. no build step.
